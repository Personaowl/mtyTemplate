\subsection{并查集}
\label{ds:dsu}
\AlgorithmInfo
    {维护集合合并、连通性和集合大小。}
    {初始化 $O(n)$；合并、查询均摊 $O(\alpha(n))$；空间 $O(n)$。}
    {元素编号 $1\ldots n$；路径压缩、按大小合并，不支持撤销。}
\subsubsection*{原理}
每个集合用一棵父亲树表示，根是集合代表。\InlineCode{find} 在递归返回时把路径上的点直接连到根；合并时把较小集合的根接到较大集合的根下，并累加根上的大小。

\subsubsection*{使用教程}
\InlineCode{init(n)} 建立 $n$ 个单点集合；\InlineCode{find(x)} 返回当前代表，\InlineCode{merge(x,y)} 合并两集合，成功合并返回真，原本同集合返回假。\InlineCode{check(x,y)} 判断是否同集合，\InlineCode{size(x)} 返回所在集合大小。重复 \InlineCode{init} 会清空合并结果。
\begin{lstlisting}[style=mtycpp,numbers=none]
DSU dsu;
dsu.init(5);
bool joined=dsu.merge(1,2);
dsu.merge(2,3);
bool ok=dsu.check(1,3);
int rt=dsu.find(2),cnt=dsu.size(1);
\end{lstlisting}
