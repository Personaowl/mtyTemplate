# 计算几何专项复核

2026-10-15，v0.12.4。覆盖第八章全部 23 个条目、22 份源码，核查实现、调用前提、数值范围和退化返回；以下是本地审查与测试范围，不表示在线评测 AC 或全输入形式证明。

## 本次确认并修复

两圆求交和交面积共用的半弦长计算存在数值消减。例：大圆中心 (0,0)、半径 1e6，小圆中心 (1000000.0005,0)、半径 0.001，原实现的交点到小圆的距离误差约 3.45e-5。大圆半径 1e6、小圆半径 1e-6、圆心距 1e6 时，交面积原来可能为 0，实际约为 1.57079632679456e-12；互换两个圆也可能改变数值结果。

修正保持原相交分类与接口：

- 用 `circle_chord(r,s,d)` 共用弦参数；半弦长由三角形面积求出，采用 [Kahan 重排海伦公式](https://people.eecs.berkeley.edu/~wkahan/Triangle.pdf)，避免从大圆的两个近等平方量求差。
- 两侧有向投影距离分别计算，按尺度选择等价表达式；从较小圆心构造弦中点，减少坐标消减。
- 交面积改为两侧圆弓形面积相加。小角分支使用 `theta-sin(2*theta)/2` 的展开式，避免几乎相等的扇形与三角形面积相减。

源码与讲解同时更新。半平面交的不等式转直线说明改为选较大系数求边界点、单位化方向后构造，避免极小系数导致构造退化；补充浮点位数和空间近平行接口的前提。这些说明调整不改变相关算法代码。

## 本轮验证

```sh
python scripts/check_geometry.py --smoke
python scripts/check_code.py
latexmk main.tex
```

几何专项在普通 int 与整数宏两种模式分别执行：每种通过 **185,304 项**几何检查、**8,032 项**面积检查、**4,540 个** Python 任意精度整数／Fraction／100 位 Decimal 参考用例。默认编译流程仍不运行行为检查。

新增高精度用例使用二进制可精确表示的半径与圆心距，将读入舍入和公式误差分开；交面积容差按小圆面积缩放，而不是统一用 `1+area` 放宽小量。新增变换检查包括整数大平移／缩放、旋转，长宽比 1e12 的矩形、任意方向内外公切线和三维构造。此前半平面交跨界、圆与多边形相切的回归继续保留。

几何构造仍有数值前提：近乎平行的无限直线、接近共线的外心、近零面积重心对输入扰动敏感；半平面交只返回与方框相交后的正面积区域，清理近点可能消去容差尺度的区域。固定 EPS 不是任意尺度下的精确判定。不可去掉这些接口条件后把测试结果推广到全实数域。
