## 五项补充：01 Trie、欧拉路径、0-1 BFS、点双与莫比乌斯（2026-10-15）

按用户指定只补这五项，归入现有数论、图论和数据结构主题，不增加其他算法。版本 v0.12，九章共 175 个条目、146 份直接引用的唯一 C++ 源码；共享依赖按各章检查清单读取。

- 01 Trie：可重复非负整数集合，插入、单次删除、重数、最大／最小异或；空集用状态区分合法的零答案。位宽 1..64，数据使用 uint64_t，置位不依赖有符号溢出；节点编号用 int32_t，删除不回收节点，空间按历史插入计。
- 0-1 BFS：双端队列维护零／一权松弛顺序，首次弹出确定距离，跳过重复点；可换源重复运行。教程明确有向加边、无向需双向添加以及不可达标记。
- 欧拉路径／回路：递归 Hierholzer 同时支持有向、无向图；无向边只加一次，两邻接项共享原边编号。先核对度数与起点，构造后检查全部边被使用；顶点序列和边序列配套，失败清空结果，允许空边集、重边和自环。递归深度按 O(m) 说明。
- 点双：递归 low-link 和算法点栈，按边编号跳过父边。low[v]>=dfn[u] 时出栈到 v 并附加 u，保留 u 供其他分量使用；根割点按搜索树儿子数判断。桥的二点块、孤立点单点块保留，自环忽略；belong[u] 记录全部归属，与边双单一 bel 区分。
- 莫比乌斯：复用 Sieve 增加 mu/pre_mu，保持既有 primes/minp/phi/prime_xor；推导约数和恒等式、因子反演、有限倍数形式与互质数对公式。附加因子反演、整除分块互质／指定 gcd 计数函数；先提升到 128 位，说明正整数有序对与实际筛表上界，不扩展超大上界求和。

参考核对（代码按当前接口自行整理，不直接复制）：[OI Wiki Trie](https://oi-wiki.org/string/trie/)、[CP-Algorithms 0-1 BFS](https://cp-algorithms.com/graph/01_bfs.html)、[CP-Algorithms Euler path](https://cp-algorithms.com/graph/euler_path.html)、[OI Wiki 双连通分量](https://oi-wiki.org/graph/bcc/)、[NIST DLMF 莫比乌斯反演](https://dlmf.nist.gov/27.5)。数学推导及位宽、邻接类型、重复构建、分量归属与复杂度按本实现核对。

| 基本性质、直径、中心、重心 | 区分选根关系和无根性质，区分 n 项 DFS 序与 2n-1 项欧拉序。直径两次最远点法限制非负权，额外一遍计算全部离心率；顶点中心按最小离心率枚举，明确带权顶点中心与边内部连续中心、零权多中心。重心按删除顶点后的最大块大小，不按最大距离 |
| 倍增与常数查询 LCA | 倍增表高按 n 动态确定，根深度 1，0 表示不存在；提供父节点跳跃、路径距离、祖先判断、DFS 区间及根路径最小边。森林接口显式传入每个块的根。RMQ 版用标准欧拉序，修正预处理复杂度表述为 O(n log n)，仅查询为 O(1) |
| 点差分、边差分 | 分别处理 LCA 与 LCA 父亲的抵消，根父亲仅为 0 号占位；边贡献对应较深端点。汇总使用副本，支持重复读取、清空更新；明确离线复杂度 |
| 重链、长链、边化点 | 重链按子树点数、长链按向下长度选儿子。重链输出按 u 到 v 顺序的区间与反转标记，边模式仅在最后同链段排除 LCA；子树内部边排除子树根的父边。长链搭配一次最高位倍增与线性链梯表，实现 O(1) 第 k 级祖先，整体预处理仍含倍增的 O(n log n)。边化点分别说明父边下放和真正插边节点 |
| 虚树构造与断边 DP | 构造沿用相邻 LCA、二次排序去重与相邻连边，始终加入固定根，只清理前一轮实际节点。通用构造与题目 DP 分离，标记只对应真实关键点；空集只保留根。断边 DP 允许非关键叶子代价为 0，关键点含根返回 -1，父层全局最小边截断与非负条件配套，儿子和使用 128 位 |
| 笛卡尔树、Kruskal 重构树 | 笛卡尔树只保留通用构造，移除题目专用 DP 与重复矩阵片段，相等值固定较小下标优先；单调栈是构造状态，不模拟 DFS。重构树使用真实边权排序、独立维护并查集代表元与树根，支持不连通森林及负权，阈值大小仅统计原叶子 |
| DSU on tree | 将参考代码的题目专用统计改为子树不同颜色数；轻子树清理、重子树保留，再合并轻子树与当前点，记录完整子树答案；复用 HLD 序号，不含线段树 |

补充参考为 [CP-Algorithms：倍增 LCA](https://cp-algorithms.com/graph/lca_binary_lifting.html)、[CP-Algorithms：重链剖分](https://cp-algorithms.com/graph/hld.html)、[OI Wiki：树的中心](https://oi-wiki.org/graph/tree-center/)、[OI Wiki：虚树](https://oi-wiki.org/graph/virtual-tree/)。长链祖先查询按“先跳最高位、再查扩展链表”的不变量独立实现与验证；没有把重链的对数跳链次数当成长链结论。
